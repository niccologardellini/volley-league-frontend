# Volley League · Frontend

Interfaccia Angular 19 + Angular Material della piattaforma Volley League. Richiede il backend in esecuzione su http://localhost:8080 (repository separato).

## Avvio

```bash
npm install
npm start
```

Poi apri http://localhost:4200. Account demo (password `password`): admin@volley.it, dirigente@4torri.it, arbitro@fipav.it, giocatore@4torri.it.
